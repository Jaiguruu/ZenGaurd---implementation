# SOAR Integration: AI Prompt Library & Developer Guide

This document contains a curated list of tactical instructions and **Copy/Paste AI Prompts**. The developer should use these prompts with their AI assistant (Claude, GitHub Copilot, Gemini) to immediately action the integrations defined in the `integration_handoff.md`.

---

## 🛠️ Developer Pre-Flight Checklist
Before using the prompts below, ensure your environment is ready:
- [ ] You have run `pip install -r requirements.txt` locally.
- [ ] You have started the UEBA API server locally using `uvicorn model_server:app --port 8000` via the UEBA directory.
- [ ] You have reviewed `integration_handoff.md` and understand the `feature_context` loopback.

---

## 🤖 Copy & Paste AI Prompts

### Topic 1: Writing the Subprocess / API Requester for the Engine
**Goal:** We need `engine.py` to stop using fake mock loops and start calling the UEBA FastAPI endpoints locally over HTTP.
**Prompt to feed your AI:**
> "I am working on the ZenGuard SOAR module. Please edit my `engine.py` script. I need you to build a Python `requests` function that sends a batch payload to `http://127.0.0.1:8000/api/soar/evaluate` and parses the returned JSON containing `risk_score` and `feature_context`. Include graceful exception handling if the UEBA server is down."

### Topic 2: Developing Contextual Deterministic Rules
**Goal:** The Reinforcement Learning agent is unpredictable. We need absolute security fallbacks using the Context features.
**Prompt to feed your AI:**
> "Inside my SOAR `engine.py`, the AI RL logic executes broad actions. I need you to implement a strict 'guardrail' function using the `feature_context` returned from the UEBA. Write an override clause that states: if `risk_score > 80` AND `feature_context['MFA_bypassed'] == 1`, bypass the RL agent completely and hard-execute the `Revoke_All_Tokens` isolation playbook."

### Topic 3: Rewiring the RL Agent State Space
**Goal:** `rl_agent.py` was likely trained on mock anomaly thresholds. We must bind it closely to the 0-100 linear score generated by the Isolation Forest translation layer.
**Prompt to feed your AI:**
> "Review my `rl_agent.py` script. Currently, its state space calculation relies on older arbitrary bounds. The upstream UEBA pipeline will now universally provide an integer `risk_score` ranging between 0 and 100. Please rewrite the state mapping logic inside the `SOARRLAgent` class so that the state discretization perfectly aligns with buckets of these 0-100 risk score bands (e.g. 0-20, 20-50, 50-80, 80-100). Also update the reward mechanics to reflect this new state space."

### Topic 4: Writing Validation Integration Tests
**Goal:** The SOAR needs to prove it can consume data from the UEBA automatically.
**Prompt to feed your AI:**
> "Please write a comprehensive integration test called `test_ueba_connection.py`. I want the script to automatically launch the UEBA endpoint locally using subprocess `uvicorn`, fire 10 distinct synthetic payloads at the endpoint to simulate varied network traffic, and assert that the SOAR engine executes different playbooks based on whether the simulated traffic bypassed MFA or not."
